# Small Moment

A simple one-page website designed to make someone's day a little lighter.

Built as a small static website for GitHub Pages, mainly for smartphone use. The idea is to let someone scan a QR code, open the page instantly, and see a calm uplifting message with an image.

## Features

- mobile-friendly one-page layout
- simple and lightweight
- uplifting message display
- image display with soft rounded styling
- random message/image change with JavaScript
- easy deployment with GitHub Pages

## Tech Stack

- HTML
- CSS
- JavaScript
- GitHub Pages
